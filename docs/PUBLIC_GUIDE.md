# 工作台操作指南

本工作台用于核查订单成交变化与反馈完整性。数据由本地模拟器生成，不代表真实交易表现。

## 监控流程

1. 选择回放场景和分析范围。
2. 调整反馈回放进度，查看当前判断、指标和通道对比。
3. 在“异常调查”中生成报告，核查支持证据与反证条件。
4. 对反馈延迟场景执行“补齐后复核”，比较同一订单窗口的修订结果。
5. 按需下载监控快照、明细样本和调查证据。

## 场景与回放

| 控件 | 说明 |
| --- | --- |
| 正常运行 | 提供正常订单与反馈的参照样本 |
| 成交反馈延迟 | 延后部分反馈的到达时间，验证数据不完整对指标的影响 |
| 真实拒单增加 | 在模拟数据中增加实际拒单结果，验证业务异常识别；不代表真实市场事件 |
| 分析范围 | 选择全部、通道 A 或通道 B。指标与调查沿用当前范围，通道均为模拟分类 |
| 反馈回放进度 | 起点为 09:30，每步推进一分钟。位置 15 对应 09:45，位置 22 对应 09:52 |
| 定位故障时刻 | 跳到 09:45，并固定业务观察窗口 |
| 补齐后复核 | 跳到 09:52，保持截至 09:45 的业务窗口，查看迟到反馈到达后的结果 |
| 连续回放 / 暂停回放 | 每约两秒推进一分钟模拟时间，可随时暂停 |
| 重置 | 恢复正常场景、全部范围、09:37、种子 42 和阈值 8；关闭附加错误数据和固定窗口 |

## 参数与指标口径

| 参数 | 说明 |
| --- | --- |
| 模拟随机种子 | 相同种子生成相同样本，用于复现和对照 |
| 固定故障观察窗口 | 到达 09:45 后固定业务截止时间，仅更新可见反馈，避免滚动窗口换样本影响比较 |
| 附加重复与孤立反馈 | 加入重复消息和无法关联订单的消息，验证去重与隔离 |
| 成交率最小下降幅度 | 设置成交告警的最低变化幅度，单位为百分点；阈值同时考虑基线波动，不影响独立的拒单与缺失规则 |

窗口结束为 09:45 时，纳入提交时间为 09:40–09:44（含两端）的有效订单。未满 60 秒的订单暂不纳入。各比例使用同一批成熟订单作为分母。

## 指标与判断

| 指标 | 定义与解释 |
| --- | --- |
| 完全成交占比 | 完全成交订单数 / 成熟订单数。标记“暂定”时，仍有反馈缺失 |
| 拒单占比 | 拒单订单数 / 成熟订单数。未收到反馈不直接算作拒单 |
| 反馈缺失率 | 无有效反馈的订单数 / 成熟订单数。缺失订单保留在分母 |
| 到达延迟 P95 | 已到达有效反馈的延迟分位数；不包括尚未到达的消息 |

“已知反馈截至”表示可见消息的到达截止时间，“业务观察窗口”表示核查的订单时间范围。历史回补只增加当时业务窗口内已经发生、但后来才收到的反馈，不会提前计入窗口之后发生的成交。

数据链路待核查表示反馈不完整，需要补齐复核；业务异常待核查表示已到达数据支持比例越界。两类问题可能并存。样本不足时不判断比例异常；未见异常仅表示未触发当前规则。

## 监控与证据

- 成交与反馈趋势：按当前已知反馈重算历史窗口，不代表当时已发布指标的存档。
- 同窗口通道对比：按各通道自己的成熟订单分母计算，汇总比例重新合计分子和分母。
- 固定窗口复核：对比窗口结束时与当前已知反馈，两行保持相同业务窗口和订单分母。
- 当前告警队列：展示当前范围内的通道判断，不是历史告警全集。
- ETL 与原始证据：展示截至回放时间的累计接入质量，与当前业务窗口指标的时间范围不同。

证据表包括原始订单、有效订单、原始反馈、清洗反馈和隔离反馈。无法归属通道的隔离消息需在“全部”范围查看。明细预览及其 CSV 导出最多包含 100 条记录；监控快照 JSON 保存当前指标、参数和证据样本，不是全量历史数据库。

## 异常调查

选择调查方式并点击“开始调查”，回放会暂停。规则调查采用固定的只读检查流程，不需要模型凭证；输入问题用于已配置的 AI 调查。AI 模式是否完成以实际返回状态为准，失败时明确标记并保留规则结果。

报告包含现象、候选原因、支持证据、反证条件、待确认事项和建议。证据编号可对应到工具返回值。候选原因不是已证实根因，反证条件说明哪些后续观察会使当前解释不足。

修改场景、种子、通道、时间或阈值后，需要重新调查；旧报告不作为当前结论展示。可下载报告与完整工具证据。
